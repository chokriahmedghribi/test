# الترقيم البريدي التونسي — تطبيق أندرويد

تطبيق للبحث عن الرموز البريدية التونسية باسم المعتمدية أو المنطقة أو الرمز، مع خريطة تفاعلية لحدود الولايات والمعتمديات.

- 4,868 منطقة، 259 معتمدية، 24 ولاية (المصدر: code-postal.tn، نوفمبر 2026)
- البحث يعمل بدون إنترنت؛ خلفية الخريطة (OpenStreetMap) تظهر عند الاتصال بالإنترنت
- حدود المعتمديات: geoBoundaries (مبسّطة، تقريبية)

## الحصول على APK

كل دفعة (push) إلى الفرع `main` تبني ملف APK تلقائيًا عبر GitHub Actions،
وتنشره في صفحة **Releases** للمستودع. افتح الصفحة من الهاتف وحمّل الملف وثبّته.

يمكن أيضًا تشغيل البناء يدويًا من تبويب **Actions ← Build APK ← Run workflow**.

## البنية

- `app/src/main/assets/index.html` — التطبيق كاملًا (الواجهة + البيانات + الخريطة)
- `app/src/main/java/.../MainActivity.java` — غلاف WebView مع النسخ إلى الحافظة وزر الرجوع
- `.github/workflows/build-apk.yml` — بناء APK ونشره
